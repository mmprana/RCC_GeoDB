# Submission Checklist

Use this before submitting to *Habitat International*, *Cities*, *Land Use Policy*, or *Information Technology for Development*. Always check the current author guidelines.

## Argument and framing

- [ ] The title matches the final contribution.
- [ ] The abstract states problem, method, artifact, findings, and contribution.
- [ ] The introduction states the gap and the research questions.
- [ ] The article does not claim a completed implementation it cannot evidence.
- [ ] The humanistic argument is visible, not decorative.
- [ ] The planning and economic significance are explicit.
- [ ] The Bangladesh context is specific, not generic.

## Literature and references

- [ ] Every in-text citation appears in the reference list.
- [ ] Every reference is cited in the text.
- [ ] DOIs and URLs are checked.
- [ ] Journal names are correctly capitalised.
- [ ] Author names with diacritics are correct.
- [ ] Legislation and standards are cited consistently.
- [ ] Grey literature (council portals, government documents) has access dates.
- [ ] No fabricated or unverifiable references.
- [ ] Citation style matches the target journal.

## Method

- [ ] Scoping review is described with databases, search strings, inclusion/exclusion, and synthesis method.
- [ ] Case selection is justified.
- [ ] Design science process is explicit.
- [ ] Evaluation criteria are stated.
- [ ] Ethics approval and consent are described.
- [ ] Limitations are candid.
- [ ] `[empirical phase]` markers are removed or completed.

## Data and artifact

- [ ] Data dictionary excerpt is accurate.
- [ ] ERD is consistent with the schema.
- [ ] Figure captions explain the design logic.
- [ ] The geodatabase artifact is described as a proof of concept, not a deployed system.
- [ ] The schema count (65 feature classes, 9 tables, 67 domains, 27 relationships) is correct.
- [ ] Any RCC figures are verified and dated.
- [ ] Sensitive data are excluded or aggregated.

## Figures and tables

- [ ] Figures are 300–600 dpi, readable in greyscale, and use accessible fonts.
- [ ] Figure text is at least 8 pt at final size.
- [ ] Tables are editable, not images.
- [ ] Tables have clear titles and notes.
- [ ] Maps include scale, north arrow, source, and data date.
- [ ] Bangla text renders correctly.
- [ ] Permissions obtained for council screenshots or logos.

## Language and length

- [ ] Word count within journal limit.
- [ ] Abstract within journal limit.
- [ ] Keywords within journal limit.
- [ ] Consistent British or American spelling.
- [ ] Technical terms defined.
- [ ] Acronyms expanded at first use.
- [ ] Humanistic voice maintained without losing precision.
- [ ] No unnecessarily defensive or over-claiming language.

## Ethics and declarations

- [ ] Ethics approval statement.
- [ ] Informed consent statement.
- [ ] Conflict of interest statement.
- [ ] Funding statement.
- [ ] Data availability statement.
- [ ] AI-assisted writing declaration, if required.
- [ ] Author contributions (CRediT), if required.
- [ ] Acknowledgements.

## Submission package

- [ ] Cover letter.
- [ ] Manuscript (blinded if required).
- [ ] Title page.
- [ ] Figures (separate files if required).
- [ ] Tables (separate files if required).
- [ ] Supplementary data dictionary.
- [ ] Supplementary literature matrix.
- [ ] Graphical abstract, if required.
- [ ] Reviewer suggestions, if required.
- [ ] ORCID and affiliations.

## Final check

- [ ] Read the manuscript aloud for flow.
- [ ] Check the argument on every page.
- [ ] Remove notes to co-authors.
- [ ] Confirm the article still answers the research questions.
- [ ] Confirm the contribution is clear in the abstract, introduction, and conclusion.
